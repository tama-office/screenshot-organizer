# Screenshot Organizer

このプログラムは、PC内の特定のフォルダに新しく入れられた画像ファイル（スクリーンショットなど）を、その画像が作成されたときにアクティブだったウィンドウの名前のフォルダに自動で振り分けるものです。

## 機能

- 指定したフォルダを監視し、新しい画像ファイルの追加を検知します。
- 画像ファイルが保存されたときのアクティブウィンドウ名を自動で取得します。
- ウィンドウ名でフォルダを作成し、画像ファイルを自動で分類して移動します。

## 使い方

1. プログラムを実行します。
2. 監視するフォルダと分類先を指定します。
3. 指定フォルダに画像ファイルが保存されると、自動でアクティブウィンドウ名のフォルダに分類されます。

## 設定

- `--watch`: 監視するフォルダ（デフォルト: ユーザーの Pictures\Screenshots）
- `--dest`: 分類後のベースフォルダ（デフォルト: ユーザーの Desktop\OrganizedScreenshots）

## 実行

```bash
python screenshot_organizer.py
```

引数を指定しない場合、プログラム起動時に日本語でフォルダを入力するよう質問します。

または、コマンドライン引数で指定:

```bash
python screenshot_organizer.py --watch "C:\Path\To\Watch" --dest "C:\Path\To\Dest"
```

Ctrl+Cで停止します。

## 注意

- Windows専用です。
- 監視対象のフォルダに実際に画像ファイルが生成される必要があります。
- 外部のスクリーンショットソフトや自動保存機能から保存された画像にも対応します。
- OneDriveや別のアプリが保存先を管理している場合、監視フォルダを正しく指定してください。
- ウィンドウ名に無効な文字が含まれている場合、フォルダ名は安全に置換されます。
